Com es llegeix: cada columna de punts representa una combinació de llenguatges. Els punts negres connectats indiquen quins llenguatges formen part d'aquella combinació. La barra de sobre mostra quants dels enquestats usen exactament aquella combinació. A l'esquerra, les barres mostren el total d'usuaris de cada llenguatge.

Què ens diu aquesta visualització?

L'enquesta del Stack Overflow 2024 va preguntar a més de 65.000 desenvolupadors de 185 països quins llenguatges havien usat extensivament durant l'últim any, permetent seleccions múltiples. He seleccionat els més populars i he analitzat com es combinen.

Algunes observacions:

  • Python sol és la combinació més freqüent. Molts científics de dades i investigadors usen Python com a únic llenguatge principal.
  • JavaScript + TypeScript és la segona, confirmant que TypeScript s'ha consolidat com l'evolució natural de JS en l'ecosistema web.
  • La combinació JS + Python + SQL + TypeScript representa el perfil "full-stack modern amb capacitats de dades".
  • Activant o desactivant els conjunts de dalt es pot veure com canvien les interseccions. Per exemple, si desactivem C# i C++, els números pugen perquè els desenvolupadors que usen aquells llenguatges es redistribueixen.

També he explorat aquestes dades amb UpSet 2.0 (Multinet), l'eina interactiva dels autors originals. Com que pot carregar lentament, he creat aquesta versió que calcula les interseccions directament al navegador a partir de les 57.321 respostes originals.
